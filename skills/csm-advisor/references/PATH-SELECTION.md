# Path Selection (Stage 3)

Choose from four pre-packaged paths using **confirmed** signals only (Confidence = Confirmed in the
Signals Summary). Do not select a path from a single usage metric, and do not treat Activate,
Deepen, Protect, and Convert and Extend as a mandatory maturity sequence.

If the customer outcome is missing ("Not ready for path selection") or the primary cause is a
non-skilling blocker, do not select a path - explain why and what must change first.

## Activate - first use

Recommend when confirmed signals include:

- Newly purchased or newly assigned licenses
- Low activation
- A substantial licensed audience has not started using Copilot
- Users do not know where or how to begin
- Basic product, application, or secure-use readiness is missing

Expected focus: launch and awareness; IT readiness; Copilot fundamentals; first meaningful use;
Teams and Outlook basics; sponsor communication; champion-led practice that helps initial use
become a habit.

## Deepen - everyday value

Recommend when confirmed signals include:

- Users are active, but usage remains shallow
- Usage is limited to basic or occasional activities
- Two or three priority workflows can be identified
- Role groups need relevant scenarios
- Users require stronger Word, Excel, PowerPoint, or workflow skills
- Process owners are ready to apply Copilot to real work

Expected focus: role-based scenarios; application skills; priority workflows; applied practice;
champion cohorts; repeatable use; customer-owned reinforcement.

## Protect - value at renewal

Recommend when confirmed signals include:

- A renewal date has been verified
- The renewal decision is approaching
- Customer value has not yet been sufficiently demonstrated
- Sponsors need value evidence
- Selected champions or power users can generate credible examples
- A business-value readout can be completed before the renewal conversation

Expected focus: sponsor alignment; power-user capabilities; priority use cases; value and cost
evidence; customer value narrative; renewal-readiness review.

Protect may be combined with Activate or Deepen when adoption or usage gaps must also be addressed.

## Convert and Extend - new use cases

Recommend when confirmed signals include:

- The customer is ready to explore or build agents
- Relevant business processes for agents have been identified
- Makers and technical owners are available
- Copilot Studio or required capabilities are available
- The customer wants to extend Microsoft 365 Copilot
- Paid value remains unproven and a value showcase may help
- Governance, security, or observability requirements for agents must be addressed

Expected focus: value showcase; agent use cases; agent creation; Copilot Studio; Copilot extension;
technical readiness; governance, observability, and agent security.

## Multiple paths

Recommend more than one path when different confirmed signals coexist. For each proposed
combination:

- Identify the **primary** path.
- Identify supporting or parallel paths.
- Explain the signal supporting each path.
- Explain whether paths should run sequentially, in parallel, or for different audiences.

## What to present in chat at Stage 3

1. Recommended path(s): primary and supporting, with the confirmed signals behind each, and the
   sequencing (sequential, parallel, or by audience).
2. Signals that were only Probable or Unconfirmed and therefore did NOT drive a choice.
3. The Microsoft Learn shortlist (see [LEARN-MODULES.md](LEARN-MODULES.md)).

Use outcome-based language. Do not present the output as a list of unrelated courses.
