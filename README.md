# CSM Advisor

A plugin for Microsoft Copilot Cowork that helps CSMs, account teams, MTTMs, and MTTs turn customer materials and Teams meeting recaps into an **evidence-based, role-based skilling plan**. It runs five stages in one go, without stopping to ask questions (add "with debug" to your request for a step-by-step debug log):

1. **Collect artifacts** - Word, PDF, text, PowerPoint, Excel files, emails, usage reports, notes, and optional Teams meeting recaps
2. **Detect signals and summarize** - customer outcome, adoption and usage signals, audiences, readiness, blockers, and missing information in a *Signals Summary* Word document
3. **Select the path** - Activate, Deepen, Protect, or Convert and Extend (alone or combined), from confirmed signals
4. **Map required skills** - each required skill is mapped to Microsoft Learn catalog items, with catalog links, in a separate *Skills Map* Word document
5. **Build the skilling plan** - a *Skilling Paths proposal* Word document with an executive summary, internal MTT review by audience, measurement plan, and 60-to-90-day review

The output is always a proposal for MTT and account-stakeholder validation.
